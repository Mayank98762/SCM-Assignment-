# Source Register v2 (4 Nov 2026)

## Tag keys

**Independence tag**

| Tag | Meaning |
|---|---|
| CO | Company, unaudited (releases, decks) |
| CA | Company, audited (financial statements, FS notes, auditor's report) |
| CE | Company echo (press repeating a release). **Never counts as corroboration.** |
| ID | Independent data (government, regulator, gazette, World Bank) |
| IA | Independent analysis (rating agencies, brokers, academics) |
| AD | Adversarial (short sellers, litigants). Used only for allegations and their outcomes; the author's interest is disclosed. |

**Verification status**

| Status | Meaning |
|---|---|
| PV | Opened and read directly |
| PS | Seen only through search-indexed text |
| TO | To obtain |
| LIT | Academic reference; bibliographic details still to be checked against the publisher |

**Corroboration rule:** a figure counts as cross-checked only when a second source has an **independent origin**.
